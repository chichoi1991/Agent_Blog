Agent 365 리소스

조직 내 AI 에이전트를 안전하게 관리·제어하는 Microsoft Agent 365 플랫폼 리소스입니다. Microsoft Copilot Acceleration Team (CAT)이 큐레이션했습니다.

시작하기 뉴스 관리/거버넌스 보안 개발자 커뮤니티

🚀 시작하기

Agent 365 제품 페이지 — 조직 전체에서 에이전트를 안전하게 관리하는 Agent 365 공식 소개
Agent 365 공식 문서 — 에이전트 레지스트리, 접근 제어, 모니터링을 위한 기술 문서 허브
Agent 365 시작 가이드 — 관리자가 Agent 365를 활성화하고 첫 번째 에이전트를 등록하는 단계별 가이드
기존 에이전트 연결하기 — Copilot Studio, M365 Agents SDK 등으로 만든 에이전트를 Agent 365에 등록
서드파티 에이전트 연결 — 외부 플랫폼(ServiceNow, Salesforce 등)의 에이전트를 Agent 365에 통합

핵심 기능

에이전트 레지스트리 (Agent Registry) — 조직 내 모든 에이전트를 한곳에서 발견하고 관리하는 중앙 레지스트리
에이전트 접근 제어 — 누가 어떤 에이전트를 사용할 수 있는지 세밀하게 제어하는 접근 정책
에이전트 시각화 및 인사이트 — 에이전트 사용 현황, 활동 흐름, 비용을 시각적으로 모니터링
에이전트 상호 운용성 — 서로 다른 플랫폼의 에이전트가 협력하는 상호 운용 시나리오
보안 기능 개요 — Agent 365의 Zero Trust 기반 보안 아키텍처와 보호 기능

⚙️ 관리 및 거버넌스

관리 센터 (Admin Center)

Admin Center 개요 — Microsoft 365 Admin Center에서 Agent 365를 관리하는 방법
에이전트 레지스트리 관리 — 조직 에이전트를 레지스트리에 등록·승인·비활성화하는 관리자 가이드
M365 Copilot 에이전트 관리 가이드 — M365 Copilot과 통합된 에이전트를 관리하는 종합 관리자 가이드

에이전트 웨비나 시리즈

레지스트리 웨비나 — 에이전트 레지스트리 설정과 관리를 다루는 전문가 웨비나
접근 제어 웨비나 — 역할 기반 에이전트 접근 정책 구성을 다루는 전문가 웨비나
ID 관리 웨비나 — 에이전트 ID를 Entra와 통합하는 방법을 다루는 전문가 웨비나
관측성(Observability) 웨비나 — 에이전트 활동 추적, 로깅, 모니터링 방법론 웨비나
보안 웨비나 — 에이전트 보안 위협 모델링과 대응 전략 웨비나

모니터링 및 관측

레지스트리 모니터링 — 등록된 에이전트의 상태와 활동을 실시간으로 모니터링하는 방법
에이전트 거버넌스 — 정책 기반으로 에이전트 동작을 제어하고 규정 준수를 보장하는 방법
Teams 에이전트 모니터링 — Teams 채널과 채팅에서 에이전트 활동을 모니터링하는 방법
M365 Copilot 에이전트 모니터링 — M365 Copilot에서 실행 중인 에이전트의 사용 및 성능 모니터링

거버넌스 리소스

거버넌스 체크리스트 — 에이전트 거버넌스 프로그램 수립을 위한 단계별 체크리스트
거버넌스 백서 — 책임 있는 AI 에이전트 거버넌스를 위한 심층 백서
