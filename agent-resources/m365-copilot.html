Autopilot 에이전트

Microsoft Scout — 연구·분석 작업을 자율적으로 수행하는 Microsoft Scout 에이전트

GA(정식 출시) 에이전트

Researcher (리서처) — 인터넷과 조직 데이터를 검색해 심층 조사 보고서를 생성
Analyst (애널리스트) — 데이터를 분석하고 인사이트와 시각화를 제공하는 에이전트
Facilitator (퍼실리테이터) — 회의 중 실시간으로 노트를 작성하고 요약하는 에이전트
Interpreter (통역사) — 회의에서 실시간 음성 통역을 제공하는 에이전트
Employee Self-Service (직원 셀프서비스) — HR, IT 정책 등 직원 셀프서비스 질문에 자동 응답하는 에이전트

Preview(미리 보기) 에이전트

Project Manager (프로젝트 매니저) — 프로젝트 계획, 작업 추적, 진행 상황 보고를 자동화하는 에이전트
Channels 에이전트 — Teams 채널에서 대화를 요약하고 인사이트를 제공하는 에이전트
Communities 에이전트 — Viva Engage 커뮤니티의 콘텐츠를 요약하고 관리하는 에이전트

Frontier(최전선) 에이전트

People 에이전트 — 조직 내 사람과 전문성을 발견하고 연결하는 에이전트
Workforce Insights 에이전트 — 팀 협업 패턴과 생산성 인사이트를 제공하는 에이전트
Learning 에이전트 — 개인화된 학습 콘텐츠를 추천하고 학습 경로를 안내하는 에이전트
