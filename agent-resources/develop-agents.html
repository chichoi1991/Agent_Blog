Develop Agents

에이전트 개발 리소스

Microsoft SDK, 프로토콜, OSS 도구를 활용하여 엔터프라이즈 AI 에이전트를 개발하기 위한 개발자 리소스입니다. Microsoft Copilot Acceleration Team (CAT)이 큐레이션했습니다.

시작하기 M365 확장 Microsoft SDK 프로토콜 OSS/서드파티 샘플 학습 커뮤니티

🚀 시작하기

에이전트 리소스 허브 — Microsoft 에이전트 개발 전체 생태계를 보여주는 공식 허브
AI 에이전트 솔루션 아키텍처 — 에이전트 시스템을 설계하기 위한 패턴과 아키텍처 원칙
에이전트 설계 지침 — 좋은 에이전트를 만들기 위한 설계 원칙 및 권장 패턴
M365 Agents SDK — Microsoft 365 Copilot를 확장하는 공식 에이전트 SDK
Copilot Studio SDK — 코드로 Copilot Studio 에이전트를 개발하는 SDK
Teams Toolkit VS Code 확장 — Visual Studio Code에서 Teams 앱과 에이전트를 개발하는 공식 확장

에이전트 아키타입

에이전트 아키타입 가이드 — 알림형, 보조형, 자율형 등 에이전트 종류별 설계 패턴

🔌 M365 Copilot 확장

M365 Copilot 확장성 개요 — Agent Store, Work IQ, SharePoint Copilot Apps를 통한 확장 방법
선언형 에이전트 (Declarative Agents) — JSON으로 에이전트 동작을 선언하여 M365 Copilot에 통합하는 방법
메시지 확장 플러그인 — Teams 메시지 확장을 M365 Copilot 플러그인으로 변환하는 방법
Microsoft Graph 커넥터 — 외부 데이터 소스를 Graph에 연결하여 Copilot에서 검색 가능하게 만들기

🛠️ Microsoft SDK

Agent Framework (MAF)

Agent Framework 소개 — 복잡한 멀티 에이전트 시스템을 구축하는 Microsoft Agent Framework 소개
MAF 퀵스타트 — Agent Framework로 첫 번째 에이전트를 만드는 단계별 가이드
MAF 메모리 관리 — 에이전트가 컨텍스트를 기억하고 참조하는 메모리 패턴
MAF 워크플로 — 순차적·병렬·조건부 에이전트 실행 워크플로 구성 방법
MAF A2A (에이전트 간 통신) — Agent-to-Agent 프로토콜로 에이전트 간 작업을 위임하는 방법
MAF 개발자 UI — 에이전트 실행을 시각적으로 디버깅하는 Developer UI 도구
MAF GitHub 저장소 — Agent Framework 오픈소스 코드, 샘플, 이슈 트래커
MAF 샘플 코드 — 다양한 에이전트 패턴을 보여주는 Agent Framework 예제 모음
MAF + Azure Functions — Azure Functions를 에이전트 도구로 통합하는 서버리스 패턴

Semantic Kernel (SK)

Semantic Kernel 공식 문서 — .NET, Python, Java를 지원하는 Microsoft 오픈소스 AI 오케스트레이션 SDK
Semantic Kernel GitHub — Semantic Kernel 오픈소스 코드 저장소 (⭐ 30K+)
SK NuGet 패키지 (.NET) — .NET 프로젝트에 Semantic Kernel을 설치하는 NuGet 패키지
SK PyPI 패키지 (Python) — Python 프로젝트에 Semantic Kernel을 설치하는 PyPI 패키지

M365 Agents SDK

M365 Agents SDK 공식 문서 — Teams, M365 Copilot, Azure Bot Service를 지원하는 통합 에이전트 SDK
M365 Agents SDK 발표 블로그 — M365 Agents SDK 출시 배경과 Bot Framework에서의 마이그레이션 안내
퀵스타트 — C# — C#으로 첫 번째 M365 에이전트를 만드는 빠른 시작 가이드
퀵스타트 — JavaScript — JavaScript/TypeScript로 M365 에이전트를 만드는 빠른 시작 가이드
퀵스타트 — Python — Python으로 M365 에이전트를 만드는 빠른 시작 가이드
M365 Agents SDK GitHub — M365 Agents SDK 오픈소스 저장소 (구 Teams AI 라이브러리)
Bot Framework 마이그레이션 가이드 — 기존 Bot Framework 봇을 M365 Agents SDK로 전환하는 마이그레이션 가이드

Copilot Studio 개발자 도구

VS Code 확장 — Copilot Studio — Visual Studio Code에서 Copilot Studio 에이전트를 코드로 개발
Power Platform CLI — 명령줄에서 Copilot Studio 에이전트를 관리하는 Power Platform CLI

Agent 365 SDK

Agent 365 SDK 공식 문서 — Agent 365 플랫폼과 통합하는 개발자 SDK 문서
Agent 365 SDK — Node.js — Node.js 환경에서 Agent 365를 통합하는 공식 SDK
Agent 365 SDK — Python — Python 환경에서 Agent 365를 통합하는 공식 SDK
Agent 365 SDK — .NET — .NET 환경에서 Agent 365를 통합하는 공식 SDK

Azure AI Foundry Agent Service SDK

Foundry Agent Service SDK 문서 — Azure AI Foundry 에이전트 서비스를 코드로 제어하는 SDK

📡 프로토콜 및 표준

A2A (Agent-to-Agent 프로토콜)

A2A 프로토콜 사양 — 서로 다른 에이전트 플랫폼 간 상호 운용을 위한 A2A 프로토콜 공식 사양
A2A GitHub — A2A 프로토콜 오픈소스 구현 코드 및 샘플

MCP (Model Context Protocol)

MCP 공식 문서 — AI 모델에 외부 데이터와 도구를 연결하는 MCP 표준 공식 문서
MCP Python SDK — Python으로 MCP 서버와 클라이언트를 구현하는 공식 SDK
MCP TypeScript SDK — TypeScript/JavaScript로 MCP를 구현하는 공식 SDK
Azure MCP 서버 — Azure 서비스를 MCP 프로토콜로 노출하는 공식 Azure MCP 서버
SK + MCP 통합 — Semantic Kernel에 MCP 플러그인을 추가하는 방법
Copilot Studio + MCP — Copilot Studio 에이전트에서 MCP 서버를 연결하여 도구를 확장하는 방법
