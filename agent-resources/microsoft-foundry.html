Microsoft Foundry 리소스

Azure AI Foundry로 엔터프라이즈급 AI 에이전트를 구축하고 운영하기 위한 리소스입니다. Microsoft Copilot Acceleration Team (CAT)이 큐레이션했습니다.

시작하기 뉴스 도입 교육 구축하기 모델/서비스 평가/개선 아키텍처 사례 샘플 커뮤니티

🚀 시작하기

Azure AI Foundry란? — 엔터프라이즈 AI 개발을 위한 통합 플랫폼 Azure AI Foundry 소개
핵심 개념 — 허브, 프로젝트, 연결, 배포 — Foundry의 허브/프로젝트/연결/배포 개념을 이해하는 기초 문서
Azure AI Foundry 포털 — 지금 바로 Azure AI Foundry 포털에 접속하여 시작하기
퀵스타트 — AI Foundry 플레이그라운드 — 코드 없이 AI Foundry 플레이그라운드에서 모델을 바로 테스트

Agent Optimizer — 에이전트 성능을 자동으로 평가하고 최적화하는 Agent Optimizer
에이전트 메모리 기능 — Foundry 에이전트가 대화 컨텍스트를 지속적으로 기억하는 메모리 기능
Toolboxes & Routines — 에이전트에 도구 세트를 묶어 제공하는 Toolboxes 및 Routines 기능

크로스 리전 배포 — 글로벌 에이전트를 위한 크로스 리전 배포 및 라우팅 기능
전체 새 기능 목록 — Azure AI Foundry 전체 릴리스 노트 및 업데이트 기록

🔧 Foundry로 구축하기

에이전트 서비스 (Agent Service)

Azure AI 에이전트 서비스란? — Foundry에서 에이전트를 만들고 배포하는 에이전트 서비스 개요
에이전트 서비스 퀵스타트 — 첫 번째 Foundry 에이전트를 만드는 단계별 빠른 시작 가이드
에이전트 도구 (Tools) — 에이전트가 사용할 수 있는 코드 실행, 파일 검색, 함수 호출 도구
Toolbox — 도구 세트 — 여러 도구를 묶어 재사용 가능한 Toolbox로 구성하는 방법
에이전트 스킬 (Skills) — 에이전트에 재사용 가능한 스킬 모듈을 추가하는 방법

Prompt Flow 마이그레이션

Prompt Flow에서 에이전트 서비스로 마이그레이션 — 기존 Prompt Flow 워크플로를 새 에이전트 서비스로 전환하는 가이드

Foundry Local

Foundry Local GA — 로컬 환경에서 AI 모델을 실행하는 Foundry Local 정식 출시
Foundry Local 시작하기 — PC나 서버에 Foundry Local을 설치하고 모델을 실행하는 방법

SDK 및 개발 도구

Azure AI SDK 개요 — Python, JavaScript 등 언어별 Azure AI SDK 사용 방법
추적(Tracing) 기반 평가 — 에이전트 실행을 추적하고 성능을 평가하는 방법
RAG 튜토리얼 — Azure AI Search와 Foundry를 결합한 RAG(검색 증강 생성) 구축 튜토리얼
VS Code 확장 — AI Foundry — Visual Studio Code에서 Foundry 프로젝트를 개발하는 확장 프로그램

Agent Framework

Agent Framework 문서 — 멀티 에이전트 시스템을 구축하는 Foundry Agent Framework 공식 문서
Agent Framework GitHub — Azure AI Agent Framework 오픈소스 코드 저장소
Python용 스킬 라이브러리 — Python 에이전트에 추가할 수 있는 재사용 가능한 스킬 모음
멀티 에이전트 참조 아키텍처 — 복잡한 작업을 분산하는 멀티 에이전트 시스템 설계 패턴

🧠 모델 및 서비스

모델 카탈로그

모델 카탈로그 — OpenAI, Meta, Mistral, DeepSeek 등 수백 개 모델을 탐색하는 카탈로그
모델 벤치마크 — 사용 사례에 맞는 모델을 선택하기 위한 성능 벤치마크 비교
서버리스 배포 — 인프라 관리 없이 모델을 바로 API로 사용하는 서버리스 배포

Model Router

Model Router — 비용과 성능을 최적화하여 요청을 적절한 모델로 자동 라우팅

Azure OpenAI 서비스

Azure OpenAI 서비스 개요 — GPT-4o, o3, o4-mini 등 OpenAI 모델을 Azure에서 사용하는 방법

Azure AI 서비스

Azure AI Vision — 이미지 분석, OCR, 얼굴 감지 등 컴퓨터 비전 서비스
Azure AI Speech — 음성 인식, 텍스트 음성 변환, 음성 번역 서비스
Azure AI Language — 감정 분석, 키워드 추출, 언어 이해 서비스
Azure AI Search — 벡터 검색과 키워드 검색을 결합한 엔터프라이즈 검색 서비스

📊 평가 및 개선

에이전트 평가

생성형 AI 앱 평가 — 에이전트 응답의 품질, 근거성, 일관성을 측정하는 평가 방법
평가 SDK — 코드로 에이전트 성능을 자동 평가하는 Azure AI Evaluation SDK
프로덕션 모니터링 — 배포된 에이전트의 성능과 품질을 지속적으로 모니터링하는 방법
Agent Optimizer — 평가 결과를 바탕으로 에이전트를 자동 최적화하는 Agent Optimizer

파인튜닝 (Fine-tuning)

지도 학습 파인튜닝 (SFT) — 레이블된 데이터로 모델을 특정 작업에 특화시키는 SFT 방법
강화 학습 파인튜닝 (RFT) — 보상 신호로 모델을 개선하는 강화 학습 기반 파인튜닝
모델 증류 (Distillation) — 대형 모델의 지식을 소형 모델로 전달하는 증류 기법
저장된 완성 (Stored Completions) — 프로덕션 응답을 자동으로 수집하여 파인튜닝 데이터로 활용하는 방법
합성 데이터 생성 — 파인튜닝용 합성 훈련 데이터를 AI로 생성하는 방법

콘텐츠 안전성

Azure AI Content Safety — 에이전트 출력에서 유해 콘텐츠를 감지하고 필터링하는 서비스

🏗️ 아키텍처 및 모범 사례

Cloud Adoption Framework (CAF)

AI 시나리오 가이드 — AI 도입 전략, 랜딩 존 설계, 계획·준비·거버넌스를 다루는 CAF

Well-Architected Framework (WAF)

AI 워크로드 Well-Architected — 신뢰성, 보안, 비용 최적화 관점에서 AI 워크로드를 설계하는 WAF

참조 아키텍처

RAG 기준선 아키텍처 (Azure AI Search) — Azure AI Search와 Azure OpenAI를 결합한 RAG 참조 아키텍처
기준선 채팅 앱 아키텍처 — 엔터프라이즈 채팅 AI 앱을 위한 기준선 참조 아키텍처

보안 및 네트워킹

Private Link 구성 — 인터넷을 통하지 않고 안전하게 Foundry에 연결하는 Private Link 설정
역할 기반 접근 제어 (RBAC) — Foundry 리소스에 대한 세밀한 접근 권한을 관리하는 RBAC 가이드
관리 ID (Managed Identity) — 자격 증명 없이 Azure 서비스 간 안전한 인증을 구현하는 관리 ID
