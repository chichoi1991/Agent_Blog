Learn about Custom Engine Agents
==
This material is a step-by-step guide for users who are creating a Custom Engine Agent with Copilot Studio for the first time.
<br/>

**Agent scenario**
---
Configure an agent that can search and explain documents, and contact the document owner or manager when needed.

**Workshop contents**
- Write Instructions
- Connect Knowledge (SharePoint)
- Add a Tool: Pre-built Connector (send email)
- Add a Flow (send channel notification, then update SPO)
- Add a Trigger
- Publish and share the agent
