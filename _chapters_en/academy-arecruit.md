The Recruit course is an introductory track for anyone starting to learn Copilot Studio agents. It takes you through the full flow: setting up the development environment, understanding core concepts, creating your first agent, configuring topics, cards, flows, and event triggers, and finally publishing and licensing.

## Modules covered in this course

1. [Start Recruit: choose your path]({{ '/en/chapters/academy-recruit-choose/' | relative_url }})  
   Compare which Recruit learning path to choose: the Standard harness or the GitHub Copilot harness.
2. [Mission 00: Course setup]({{ '/en/chapters/academy-recruit-00-course-setup/' | relative_url }})  
   Prepare your Microsoft 365 account, Copilot Studio trial, development environment, and SharePoint site.
3. [Mission 01: Introduction to agents]({{ '/en/chapters/academy-recruit-01-introduction-to-agents/' | relative_url }})  
   Understand conversational AI, LLMs, RAG, and the difference between conversational and autonomous agents.
4. [Mission 02: Copilot Studio fundamentals]({{ '/en/chapters/academy-recruit-02-copilot-studio-fundamentals/' | relative_url }})  
   Learn the core structure of a Copilot Studio agent: Knowledge, Tools, Topics, and Instructions.
5. [Mission 03: Create a declarative agent for Microsoft 365 Copilot]({{ '/en/chapters/academy-recruit-03-create-a-declarative-agent-for-m365copilot/' | relative_url }})  
   Create a declarative agent for Microsoft 365 Copilot using prompts and organizational knowledge.
6. [Mission 04: Create a solution for agents]({{ '/en/chapters/academy-recruit-04-creating-a-solution/' | relative_url }})  
   Learn how to package agents into reusable solutions for management and deployment across environments.
7. [Mission 05: Use prebuilt agents]({{ '/en/chapters/academy-recruit-05-using-prebuilt-agents/' | relative_url }})  
   Learn how to use and customize template agents to get started faster.
8. [Mission 06: Create a custom agent with natural language and AI]({{ '/en/chapters/academy-recruit-06-create-agent-from-conversation/' | relative_url }})  
   Learn how to create an agent using only natural language and ground it with knowledge sources such as SharePoint, documents, and websites.
9. [Mission 07: Add a new topic with triggers and nodes]({{ '/en/chapters/academy-recruit-07-add-new-topic-with-trigger/' | relative_url }})  
   Learn how to define custom question-and-answer paths with Topics.
10. [Mission 08: Enhance user interaction in Topics with Adaptive Cards]({{ '/en/chapters/academy-recruit-08-add-adaptive-card/' | relative_url }})  
    Learn how to create Adaptive Cards using Power Fx and SharePoint.
11. [Mission 09: Automate by adding an agent flow to a topic]({{ '/en/chapters/academy-recruit-09-add-an-agent-flow/' | relative_url }})  
    Learn how to trigger a backend flow from Adaptive Card input.
12. [Mission 10: Add event triggers to enable autonomous agent capabilities]({{ '/en/chapters/academy-recruit-10-add-event-triggers/' | relative_url }})  
    Configure the agent to act autonomously with event-based logic.
13. [Mission 11: Publish your agent and deploy it to Teams and Microsoft 365 Copilot]({{ '/en/chapters/academy-recruit-11-publish-your-agent/' | relative_url }})  
    Deploy your agent to Microsoft Teams and Microsoft 365 Copilot.
14. [Mission 12: Understand Copilot Studio licensing]({{ '/en/chapters/academy-recruit-12-understanding-licensing/' | relative_url }})  
    Learn how Copilot Studio licensing and billing work.
15. [Final mission: Earn your Recruit badge]({{ '/en/chapters/academy-recruit-course-completion-badges-recruit/' | relative_url }})  
    Learn how to request a badge and officially record your learning achievement.

If this is your first time, we recommend following the modules in order. If you want to quickly review a specific capability, you can open the module you need directly.
