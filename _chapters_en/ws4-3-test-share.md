## Step 3: Test and share the agent

# 3. Test and share the agent
After the agent is created, you can call and use it from Copilot,
and you can test it in the test panel.

## 3.1 Validate the agent in the Test pane

Test insight analysis in the test panel on the right side of the agent authoring window. <br>
```
Analyze insights before my meeting with [user name]
```
<br>
<img width="952" height="596" alt="image" src="https://github.com/user-attachments/assets/ab9f9b35-591e-4bb3-b80f-a2fb166f3740" />

<br>

If the desired answer or format does not appear, edit the Instructions so the agent can provide the result you want.

<br>

## 3.2 Use the agent in Copilot
The completed agent can be found in Copilot, and you can pin it if needed and use it freely.
<img width="1199" height="672" alt="image" src="https://github.com/user-attachments/assets/af2b399b-569d-4c1f-b0f9-8efb3a0bff46" />
<br>
To see all agents available to you, select **All agents** and check **My agents**.
<img width="1197" height="666" alt="image" src="https://github.com/user-attachments/assets/8ab98d80-d128-45e7-ba96-2a5d939d69d1" />
<br>

## 3.3 Share the agent

The completed agent can be shared and used among users who have M365 Copilot.
> For users without an M365 Copilot license to use the agent, tenant administrator settings are required.

Click ... on the agent you created and share it with other organizations or people through Share.
<img width="678" height="482" alt="image" src="https://github.com/user-attachments/assets/18017611-ac5d-4bfb-97be-0dc2e9ae36c0" />
<br>
After clicking the Share button, choose whether to share with the entire organization, specific people, groups, and so on.
<br>
<img width="1200" height="615" alt="image" src="https://github.com/user-attachments/assets/47e7d1f7-7732-4d05-a3e8-1342616902a6" />
<br>

Users with a license can use the agent through the selected link.
> Users without an M365 Copilot license, or users for whom administrator settings have not been completed, cannot use this agent.
<img width="1200" height="643" alt="image" src="https://github.com/user-attachments/assets/3c88f648-db00-476e-86b0-d901317743c4" />

The completed agent can be used not only in Teams, but also in various Office apps.
