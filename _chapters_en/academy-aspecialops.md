Special Ops is a collection of standalone, hands-on labs from Copilot Studio Agent Academy. Each mission focuses deeply on a specific technology or integration scenario. You can complete each lab independently, regardless of course order, and earn a badge when you finish.

## Modules covered in this lab series

1. [🔎 Azure AI Search RAG]({{ '/en/chapters/academy-special-ops-azure-ai-search-rag/' | relative_url }})  
   Build RAG with Azure AI Search vector search to answer from grounded organizational documents.

2. [🤖 Microsoft Copilot Studio ❤️ MCP]({{ '/en/chapters/academy-special-ops-mcs-mcp/' | relative_url }})  
   Practice deploying an MCP server and connecting it to Microsoft Copilot Studio.

3. [📚 Microsoft Learn MCP Server]({{ '/en/chapters/academy-special-ops-ms-learn-mcp/' | relative_url }})  
   Connect the Microsoft Learn Docs MCP Server to a Copilot Studio agent for real-time documentation access.

4. [⚡ Power Platform CLI MCP Server]({{ '/en/chapters/academy-special-ops-pac-cli-mcp/' | relative_url }})  
   Connect Power Platform CLI and GitHub Copilot through MCP to manage your tenant with natural-language commands.

5. [🎯 Improve Power Platform Tenant Governance Strategy Plan]({{ '/en/chapters/academy-special-ops-pac-cli-mcp-power-platform-plan/' | relative_url }})  
   Review an example AI-generated report for a Power Platform tenant governance strategy plan.

6. [🧬 YAML Specialist]({{ '/en/chapters/academy-special-ops-yaml-specialist/' | relative_url }})  
   Use VS Code and the YAML agent definition language to build and extend Copilot Studio agents fully as code.

7. [📄 Microsoft Copilot Studio + Docusign MCP]({{ '/en/chapters/academy-special-ops-docusign-mcp/' | relative_url }})  
   Connect the Docusign MCP Demo server to a Copilot Studio agent and trigger Workflow Builder automation.

8. [🔐 Connect to a Secure MCP Server with OAuth 2.0]({{ '/en/chapters/academy-special-ops-mcp-oauth/' | relative_url }})  
   Learn how to connect a Copilot Studio agent to an MCP server protected with OAuth 2.0 authentication.

9. [✍️ Operation Ghostwriter: Build a marketing content agent with Skills]({{ '/en/chapters/academy-special-ops-ghostwriter/' | relative_url }})  
   Build a marketing content agent in a modern way using Skills instead of one large instruction block.

Each lab can be completed independently, but working through the MCP-based labs in order can help build your understanding.
