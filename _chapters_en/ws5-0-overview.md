# [Renewal] Explore the basic features of Copilot Studio

## 🎯 Workshop goals

Understand and use the **basic features provided by Copilot Studio**.  
This workshop reorganizes the key content from the previous Basics #1, #2, and #3 workshops into a single flow,  
so you can experience the full lifecycle in one lab: **agent creation → Instructions → Knowledge → MCP/connector tools → Flows/Triggers → prompt tools → Excel data usage → deployment**.

<br>

---

## 🧩 Main features covered in this workshop

| Category | Feature |
|----------|------|
| **Agent basics** | Agent creation, environment/language settings, basic Instructions writing |
| **Knowledge** | Connect external knowledge sources such as SharePoint documents and web search |
| **Tools** | Built-in MCP, connectors, external (private) MCP servers, prompt tools |
| **Automation** | Power Automate Flows, Triggers (event-based automatic execution) |
| **Data usage** | Excel (SharePoint)-based time-series data filtering and analysis |
| **Deployment** | Publish, Microsoft Teams channel connection, monitoring |

## ✅ Prerequisites

- Access to Copilot Studio (lab environment recommended)
- Microsoft 365 account (for SharePoint, Outlook, and Teams)
- SharePoint library / Teams team and channel for the lab
- (Step 6) External MCP server URL and API Key (instructor guidance or self-deployment)
- (Step 10) Excel file uploaded to SharePoint (converted to a table)
