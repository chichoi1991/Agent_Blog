**환영합니다, Recruit.**  
여러분의 미션은, 받아들이겠다면, **Microsoft Copilot Studio**로 에이전트를 만드는 기술을 익히는 것입니다.

이 실습형 교육은 **에이전트의 세계**로 들어가는 입문 지점입니다. Recruit 과정에는 두 가지 경로가 있으며, 둘 다 기초부터 시작합니다. 만들고 싶은 에이전트 유형에 맞는 경로를 선택하세요.

## 🧬 이 과정이 적합한 대상

이 과정은 다음과 같은 분에게 적합합니다.

- **Copilot Studio**를 탐색하는 maker와 developer
- **Microsoft 365 Copilot 확장**을 만드는 IT 전문가
- 지능형 에이전트로 **역량을 높이고 싶은** Power Platform 사용자
- **직접 만들어 보며** 배우는 방식을 선호하는 모든 사람

## 🧭 경로 선택하기

Recruit 과정은 같은 IT 지원 시나리오를 두 가지 방식으로 학습할 수 있게 구성되어 있습니다.

- **Standard harness 경로**: Copilot Studio의 classic experience에서 토픽, 트리거, 노드, 분기 등 구조화된 대화 흐름을 설계합니다.
- **GitHub Copilot harness 경로**: Copilot Studio의 **New experience**에서 instructions, skills, tools, workflows를 사용해 목표 중심으로 추론하는 에이전트를 만듭니다.

### 🤔 어떤 경로를 선택해야 할까요?

Copilot Studio는 **harness** 위에서 에이전트를 실행합니다. harness는 런타임으로, 언제 모델을 호출할지, 어떤 구성 요소를 전달할지, 어떤 도구를 실행할지 결정합니다. 두 Recruit 경로는 서로 다른 harness를 가르칩니다.

| | Standard harness | GitHub Copilot harness |
| --- | --- | --- |
| **설계하는 것** | Topics, triggers, nodes, branches | Instructions, skills, tools, workflows |
| **에이전트가 따르는 방식** | 사용자가 작성한 대화 경로 | 목표를 향해 추론해 낸 계획 |
| **가장 적합한 경우** | 규칙 기반 에이전트와 구조화되고 반복 가능한 대화 | 복잡하고 추론이 많으며 여러 단계로 이루어진 비즈니스 프로세스 |
| **작성 화면** | Classic experience | Copilot Studio의 **New experience** 토글 |

<div class="info-box note" markdown="1">
**팁**

확신이 없다면 Adaptive Cards, Power Fx, agent flows를 포함해 Copilot Studio를 가장 폭넓게 다루는 **standard harness**로 시작하세요. 현재 new experience에서 에이전트를 만들고 있고 instruction-driven 접근 방식을 배우고 싶다면 **GitHub Copilot harness**로 시작하세요.
</div>

두 경로 모두 같은 IT 지원 시나리오를 사용하므로, 한 경로를 완료하면 다른 경로도 더 쉽게 따라갈 수 있습니다. 두 경로를 모두 완료할 필요는 없습니다.
