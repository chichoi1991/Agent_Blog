## 🎯 미션 브리핑

축하합니다, Recruit. 훈련을 마쳤습니다. 이제 **공식적으로 인증받을 차례** 입니다.

이 마지막 미션은 다음을 확인합니다.

- 직접 실습을 완료했는지
- 결과물이 실제 환경에서 동작하는지
- 배지가 정확하고 공정하게 발급되는지

## 🏅 Recruit 배지 받기

모든 Agent Academy 경로(**Recruit → Operative → Commander**)에는 [Global AI Community](https://globalai.community/)를 통해 발급되는 공식 디지털 배지가 있습니다.

이 배지는 다음과 같은 특징이 있습니다.

- 검증 가능함
- 공유 가능함(LinkedIn, 이력서, 포트폴리오 등)
- 단순 참석이 아니라 실제 기술 작업을 기반으로 함

배지의 의미를 유지하기 위해 Agent Academy는 **엄격한 검증 절차** 를 따릅니다.

<div class="info-box note" markdown="1">
**중요**

**Recruit 경로에서 만든 IT Help Desk Agent만 이 배지의 대상입니다.**
</div>

### 🧭 제출 절차

아래 단계를 **순서대로 모두** 수행하세요.

### 1. ⭐ Agent Academy GitHub Repo에 Star 남기기

👉 [Agent Academy GitHub Repo](https://github.com/microsoft/agent-academy)

**왜 중요한가요?**

- 더 많은 사람이 Academy를 발견하도록 돕습니다.
- 커뮤니티 참여가 활발하다는 신호가 됩니다.
- 프로젝트에 대한 지속적인 투자에 직접 도움이 됩니다.

Star는 빠르고 무료이며, 배지 자격 요건에 포함됩니다.

### 2. 🧾 Badge Validation Form 작성하기

👉 [Badge Validation Form](https://aka.ms/agent-academy-recruit/form)

이 양식은 다음을 수행합니다.

- Recruit 경로 관련 질문으로 실제 커리큘럼 완료 여부 확인
- Agent Academy 개선을 위한 피드백 수집
- 배지를 받을 정확한 이메일 수집
- Global AI Community를 통한 배지 수령 동의 확인

### 3. 🔐 Global AI Community 계정 만들기 및 로그인하기

👉 [Global AI Community Account Log In](https://globalai.community/auth/login)

배지는 **Global AI Community 플랫폼** 을 통해 발급됩니다.

계정이 없다면 다음을 꼭 지켜 주세요.

- badge request form에 입력한 것과 **같은 이메일** 로 무료 계정을 만드세요. 이메일이 다르면 배지를 전달할 수 없습니다.

계정이 없으면 유효한 제출을 했더라도 배지가 발급되지 않습니다.

<div class="info-box note" markdown="1">
**중요**

**배지 요청 양식의 이메일과 Global AI Community 계정 이메일이 정확히 일치해야 합니다.** 다르면 배지가 전달되지 않습니다.
</div>
