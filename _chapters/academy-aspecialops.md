<div class="info-box note" markdown="1">
**원문 번역 안내** — 이 페이지는 [Copilot Studio Agent Academy](https://microsoft.github.io/agent-academy/)의 [Special Ops 랩 섹션](https://microsoft.github.io/agent-academy/special-ops/)을 바탕으로, 현재 게시된 독립 랩 전체를 한국어로 모아 안내하는 랜딩 페이지입니다. 세부 표현은 각 원문이 우선합니다.
</div>

Special Ops는 Copilot Studio Agent Academy의 독립 실전 랩 모음으로, 특정 기술이나 통합 시나리오에 집중적으로 파고드는 미션 단위 학습을 제공합니다. 각 랩은 코스 순서와 무관하게 독립적으로 수행할 수 있으며, 완료 시 배지를 획득할 수 있습니다.

## 이 랩 시리즈에서 다루는 모듈

1. [🔎 Azure AI Search RAG]({{ '/chapters/academy-special-ops-azure-ai-search-rag/' | relative_url }})  
   Azure AI Search 벡터 검색으로 RAG를 구성해 조직 문서 근거 기반 답변을 구현합니다.

2. [🤖 Microsoft Copilot Studio ❤️ MCP]({{ '/chapters/academy-special-ops-mcs-mcp/' | relative_url }})  
   MCP 서버를 배포하고 Microsoft Copilot Studio에 연결하는 방법을 실습합니다.

3. [📚 Microsoft Learn MCP Server]({{ '/chapters/academy-special-ops-ms-learn-mcp/' | relative_url }})  
   Microsoft Learn Docs MCP Server를 Copilot Studio 에이전트에 연결해 실시간 문서 접근을 구현합니다.

4. [⚡ Power Platform CLI MCP Server]({{ '/chapters/academy-special-ops-pac-cli-mcp/' | relative_url }})  
   Power Platform CLI와 GitHub Copilot을 MCP로 연결해 자연어 명령으로 테넌트를 관리합니다.

5. [🎯 Power Platform 테넌트 거버넌스 전략 개선 계획]({{ '/chapters/academy-special-ops-pac-cli-mcp-power-platform-plan/' | relative_url }})  
   AI로 생성한 Power Platform 테넌트 거버넌스 전략 계획 예시 보고서입니다.

6. [🧬 YAML Specialist]({{ '/chapters/academy-special-ops-yaml-specialist/' | relative_url }})  
   VS Code와 YAML 에이전트 정의 언어를 사용해 Copilot Studio 에이전트를 완전히 코드로 빌드·확장합니다.

7. [📄 Microsoft Copilot Studio + Docusign MCP]({{ '/chapters/academy-special-ops-docusign-mcp/' | relative_url }})  
   Docusign MCP Demo 서버를 Copilot Studio 에이전트에 연결하고 Workflow Builder 자동화를 트리거합니다.

각 랩은 독립적으로 수행할 수 있지만, MCP 기반 랩들을 순서대로 진행하면 이해도를 높일 수 있습니다.
