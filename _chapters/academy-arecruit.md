<div class="info-box note translated-post" markdown="1">
**원문 번역 안내** — 이 페이지는 [Copilot Studio Agent Academy](https://microsoft.github.io/agent-academy/)의 [Recruit 과정](https://microsoft.github.io/agent-academy/recruit/)을 바탕으로, 현재 게시된 Recruit 모듈 전체를 한국어로 모아 안내하는 랜딩 페이지입니다. 세부 표현은 각 원문이 우선합니다.
</div>

Recruit 과정은 Copilot Studio 에이전트 학습을 처음 시작하는 분을 위한 입문 트랙입니다. 개발 환경 준비, 핵심 개념 이해, 첫 에이전트 제작, 토픽·카드·플로우·이벤트 트리거 구성, 게시와 라이선스까지 한 흐름으로 익힐 수 있습니다.

## 이 코스에서 다루는 모듈

1. [Recruit 시작: 경로 선택]({{ '/chapters/academy-recruit-choose/' | relative_url }})  
   Standard harness와 GitHub Copilot harness 중 어떤 Recruit 학습 경로를 선택할지 비교합니다.
2. [미션 00: 과정 준비]({{ '/chapters/academy-recruit-00-course-setup/' | relative_url }})  
   Microsoft 365 계정, Copilot Studio 체험판, 개발 환경, SharePoint 사이트를 준비합니다.
3. [미션 01: 에이전트 소개]({{ '/chapters/academy-recruit-01-introduction-to-agents/' | relative_url }})  
   대화형 AI, LLM, RAG, 대화형 에이전트와 자율형 에이전트의 차이를 이해합니다.
4. [미션 02: Copilot Studio 기초]({{ '/chapters/academy-recruit-02-copilot-studio-fundamentals/' | relative_url }})  
   Knowledge, Tools, Topics, Instructions로 이루어진 Copilot Studio 에이전트의 핵심 구조를 배웁니다.
5. [미션 03: Microsoft 365 Copilot용 선언형 에이전트 배포]({{ '/chapters/academy-recruit-03-create-a-declarative-agent-for-m365copilot/' | relative_url }})  
   프롬프트와 조직 지식을 활용해 Microsoft 365 Copilot용 선언형 에이전트를 만듭니다.
6. [미션 04: 에이전트를 위한 솔루션 만들기]({{ '/chapters/academy-recruit-04-creating-a-solution/' | relative_url }})  
   환경 간 관리와 배포를 위해 에이전트를 재사용 가능한 솔루션으로 패키징하는 방법을 배웁니다.
7. [미션 05: 사전 구축 에이전트 활용하기]({{ '/chapters/academy-recruit-05-using-prebuilt-agents/' | relative_url }})  
   템플릿 에이전트를 사용하고 사용자 지정해 더 빠르게 시작하는 방법을 배웁니다.
8. [미션 06: 자연어와 AI로 커스텀 에이전트 만들기]({{ '/chapters/academy-recruit-06-create-agent-from-conversation/' | relative_url }})  
   자연어만으로 에이전트를 생성하고 SharePoint, 문서, 웹사이트 등 지식 소스로 그라운딩하는 방법을 배웁니다.
9. [미션 07: 트리거와 노드가 있는 새 토픽 추가하기]({{ '/chapters/academy-recruit-07-add-new-topic-with-trigger/' | relative_url }})  
   Topics로 커스텀 질문/답변 경로를 정의하는 방법을 배웁니다.
10. [미션 08: Adaptive Card로 Topics의 사용자 상호작용 강화하기]({{ '/chapters/academy-recruit-08-add-adaptive-card/' | relative_url }})  
   Power Fx와 SharePoint를 사용해 Adaptive Card를 만드는 방법을 배웁니다.
11. [미션 09: 토픽에 에이전트 흐름 추가해 자동화하기]({{ '/chapters/academy-recruit-09-add-an-agent-flow/' | relative_url }})  
    Adaptive Card 입력으로 백엔드 흐름을 트리거하는 방법을 배웁니다.
12. [미션 10: Event Trigger 추가로 자율형 에이전트 기능 활성화]({{ '/chapters/academy-recruit-10-add-event-triggers/' | relative_url }})  
    이벤트 기반 로직으로 에이전트가 자율적으로 동작하도록 구성합니다.
13. [미션 11: 에이전트를 게시하고 Teams와 Microsoft 365 Copilot에 배포하기]({{ '/chapters/academy-recruit-11-publish-your-agent/' | relative_url }})  
    에이전트를 Microsoft Teams와 Microsoft 365 Copilot에 배포합니다.
14. [미션 12: Copilot Studio 라이선싱 이해하기]({{ '/chapters/academy-recruit-12-understanding-licensing/' | relative_url }})  
    Copilot Studio의 라이선싱과 과금 방식이 어떻게 동작하는지 배웁니다.
15. [최종 미션: Recruit 배지 획득하기]({{ '/chapters/academy-recruit-course-completion-badges-recruit/' | relative_url }})  
    배지를 신청하고 학습 성과를 공식적으로 남기는 방법을 안내합니다.

처음이라면 위 순서대로 진행하는 것을 권장합니다. 특정 기능만 빠르게 보고 싶다면 필요한 모듈부터 바로 열어도 됩니다.
