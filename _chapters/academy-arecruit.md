<div class="info-box note translated-post" markdown="1">
**원문 번역 안내** — 이 페이지는 [Copilot Studio Agent Academy](https://microsoft.github.io/agent-academy/)의 [Recruit 과정](https://microsoft.github.io/agent-academy/recruit/)을 바탕으로, 현재 게시된 Recruit 모듈 전체를 한국어로 모아 안내하는 랜딩 페이지입니다. 세부 표현은 각 원문이 우선합니다.
</div>

Recruit 과정은 Copilot Studio 에이전트 학습을 처음 시작하는 분을 위한 입문 트랙입니다. 개발 환경 준비, 핵심 개념 이해, 첫 에이전트 제작, 토픽·카드·플로우·이벤트 트리거 구성, 게시와 라이선스까지 한 흐름으로 익힐 수 있습니다.

## 이 코스에서 다루는 모듈

1. [미션 00: 과정 준비]({{ '/chapters/academy-recruit-00-course-setup/' | relative_url }})  
   Microsoft 365 계정, Copilot Studio 체험판, 개발 환경, SharePoint 사이트를 준비합니다.
2. [미션 01: 에이전트 소개]({{ '/chapters/academy-recruit-01-introduction-to-agents/' | relative_url }})  
   대화형 AI, LLM, RAG, 대화형 에이전트와 자율형 에이전트의 차이를 이해합니다.
3. [미션 02: Copilot Studio 기초]({{ '/chapters/academy-recruit-02-copilot-studio-fundamentals/' | relative_url }})  
   Knowledge, Tools, Topics, Instructions로 이루어진 Copilot Studio 에이전트의 핵심 구조를 배웁니다.
4. [미션 03: Microsoft 365 Copilot용 선언형 에이전트 배포]({{ '/chapters/academy-recruit-03-create-a-declarative-agent-for-M365Copilot/' | relative_url }})  
   프롬프트와 조직 지식을 활용해 Microsoft 365 Copilot용 선언형 에이전트를 만듭니다.
5. [미션 04: 에이전트를 위한 Solution 만들기]({{ '/chapters/academy-recruit-04-creating-a-solution/' | relative_url }})  
   Solution과 Publisher 개념을 이해하고 에이전트 자산을 체계적으로 관리하는 방법을 익힙니다.
6. [미션 05: 사전 구축 에이전트 활용]({{ '/chapters/academy-recruit-05-using-prebuilt-agents/' | relative_url }})  
   템플릿 기반 에이전트로 빠르게 시작하고 테스트·게시 흐름을 경험합니다.
7. [미션 06: 대화로 사용자 지정 에이전트 만들기]({{ '/chapters/academy-recruit-06-create-agent-from-conversation/' | relative_url }})  
   자연어로 에이전트를 생성하고 SharePoint·문서 지식으로 grounding하는 방법을 배웁니다.
8. [미션 07: 새 토픽과 트리거 추가]({{ '/chapters/academy-recruit-07-add-new-topic-with-trigger/' | relative_url }})  
   토픽, 트리거 구문, 노드, Power Fx, 커넥터 도구를 활용해 대화 흐름을 설계합니다.
9. [미션 08: Adaptive Card 추가]({{ '/chapters/academy-recruit-08-add-adaptive-card/' | relative_url }})  
   Adaptive Card로 사용자 입력 경험을 개선하고 토픽 상호작용을 풍부하게 만듭니다.
10. [미션 09: Agent Flow 추가]({{ '/chapters/academy-recruit-09-add-an-agent-flow/' | relative_url }})  
    Agent flow를 이용해 자동화 단계를 구성하고 토픽과 연결하는 방법을 다룹니다.
11. [미션 10: Event Trigger 추가]({{ '/chapters/academy-recruit-10-add-event-triggers/' | relative_url }})  
    외부 이벤트로 자율형 에이전트를 시작하는 트리거와 페이로드 설계를 배웁니다.
12. [미션 11: 에이전트 게시]({{ '/chapters/academy-recruit-11-publish-your-agent/' | relative_url }})  
    Teams와 Microsoft 365 Copilot 채널에 게시하고 배포 범위를 조정합니다.
13. [미션 12: 라이선스 이해하기]({{ '/chapters/academy-recruit-12-understanding-licensing/' | relative_url }})  
    Copilot Credits, 용량 팩, PAYGO, M365 Copilot 포함 범위를 이해합니다.
14. [최종 미션: Recruit 배지 획득]({{ '/chapters/academy-recruit-course-completion-badges-recruit/' | relative_url }})  
    과정 완료 배지를 받기 위한 제출 절차와 커뮤니티 계정 준비 단계를 확인합니다.

처음이라면 위 순서대로 진행하는 것을 권장합니다. 특정 기능만 빠르게 보고 싶다면 필요한 모듈부터 바로 열어도 됩니다.
