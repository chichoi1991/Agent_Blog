## 0. 목표 및 결과물

> **▶ 이 실습에서 만들 것:** SharePoint에 올라온 **판매 엑셀을 분석** 하고, **Word 안내 문서를 참조** 해 답하며, 필요하면 **HTML 대시보드를 만들고 메일로 발송** 하는 에이전트.

### 0.1 시나리오

한 흐름에 6요소가 모두 맞물립니다 — **참고자료**(엑셀) → **스킬+도구**(분석·디자인) → **확인 게이트**(지침) → **발송**(메일 도구).

```
┌─ 사용자 ──────────────────────────┐
│ "5개 관점으로 우선 고객 뽑아줘"      │
└───────────────┬───────────────────┘
                ▼
 [참고자료]  SharePoint 엑셀 검색
                ▼
 [분석 스킬 + 코드 인터프리터]  1,000명 데이터 정확히 집계
                ▼
   ▶ 관점별 우선 고객 표 + 인사이트
                │
┌─ 사용자 ──────────────────────────┐
│ "HTML 대시보드로 만들어줘"          │
└───────────────┬───────────────────┘
                ▼
 [메일·보고서 스킬]  회사 디자인(아이보리·마젠타)
                ▼
   ▶ 대시보드 HTML 생성·저장 (다운로드 가능)
                │
┌─ 사용자 ──────────────────────────┐
│ "나에게 메일로 보내줘"              │
└───────────────┬───────────────────┘
                ▼
 [OneDrive MCP]  업로드 → 링크 첨부
                ▼
        { 발송 전 확인 } ── 미리보기 제시
                ▼
┌─ 사용자 ──────────────────────────┐
│ "발송해"                           │
└───────────────┬───────────────────┘
                ▼
 [Mail MCP]  확인 후 발송 ✅
```

### 0.2 완성 에이전트의 6요소 구성

| 요소 | 이 실습에서의 구현 | 다루는 단계 |
|---|---|---|
| **지침** | "정확히 계산 / 디자인은 스킬 / 보내기 전 확인" | 1단계 |
| **단일 스킬** | 결과를 고정 형식으로 요약하는 브리핑 스킬 | 2단계 |
| **스킬 패키지** | 분석 규칙 + 메일·보고서(디자인·템플릿 동봉) | 3단계 |
| **도구** | Mail MCP · OneDrive MCP (+ 코드 인터프리터) | 4단계 |
| **참고자료** | SharePoint 판매 엑셀 + 안내 Word | 1·4단계 |
| **메모리** | 세션 내 대화 추적(코어 자동) | — |

### 0.3 결과물 미리보기

- **분석**: 6개 관점(교체주기 초과·배터리 노후·할부 완료·기기 상태·헤비유저·종합 점수)별 우선 고객 목록 + 인사이트
- **대시보드**: KPI 카드 + 바 차트 + 관점별 표가 담긴 단일 HTML 파일(다운로드 가능)
- **메일**: 회사 디자인이 적용된 본문 + 대시보드 링크 첨부, 발송 전 확인

- New Copilot Studio 프리뷰 접근 권한
