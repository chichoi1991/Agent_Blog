**환영합니다, Operative.**  
여러분의 미션은 **Microsoft Copilot Studio**로 **멀티 에이전트 채용 시스템**을 구축하는 것입니다.

이 실습형 과정은 Recruit에서 배운 기초 위에 쌓아 올립니다. Operative 과정에는 두 가지 경로가 있으며, 둘 다 이력서 접수부터 면접 준비까지 같은 채용 시나리오를 다룹니다. 만들고 싶은 에이전트 유형에 맞는 경로를 선택하세요.

## 🧬 이 과정이 적합한 대상

이 과정은 다음과 같은 분에게 적합합니다.

- 멀티 에이전트 시스템을 설계하는 **솔루션 아키텍트**
- Dataverse와 비즈니스 도구로 에이전트를 만드는 **개발자**
- AI 안전과 사람의 감독(human oversight)을 구현하는 **IT 전문가**
- **Recruit**를 완료하고 더 고급 솔루션을 만들고 싶은 모든 사람

## 🧭 경로 선택하기

Operative 과정은 같은 채용 시나리오를 두 가지 방식으로 학습할 수 있게 구성되어 있습니다. 원하는 학습 흐름을 선택해 시작하세요.

- **Standard Harness 경로 시작**: [Operative (Standard)](https://microsoft.github.io/agent-academy/operative/01-get-started/)
- **GitHub Copilot harness 경로 시작**: [Operative (GitHub Copilot harness)](https://microsoft.github.io/agent-academy/operative-nextgen/01-get-started/)

### 🤔 어떤 경로를 선택해야 할까요?

Copilot Studio는 **harness** 위에서 에이전트를 실행합니다. harness는 런타임으로, 언제 모델을 호출할지, 어떤 구성 요소를 전달할지, 어떤 도구를 실행할지 결정합니다. 두 Operative 경로는 서로 다른 harness를 가르칩니다.

| | Standard Harness | GitHub Copilot harness |
| --- | --- | --- |
| **설계하는 것** | Connected agents, prompts, agent flows, Adaptive Cards | Instructions, skills, MCP tools, connected agents, workflows |
| **에이전트가 따르는 방식** | 사용자가 작성한 지침과, 반복 가능한 작업을 정의하는 prompts·flows | skills와 tools를 활용해 추론해 낸 계획, 그리고 정해진 단계를 제어하는 workflows |
| **가장 적합한 경우** | 로직을 직접 작성하는 구조화된 채용 워크플로 | 추론이 많고 여러 단계로 이루어진 채용 워크플로 |
| **작성 화면** | Copilot Studio의 Standard Harness | New Copilot Studio experience |

<div class="info-box note" markdown="1">
**팁**

prompts, agent flows, Adaptive Cards로 만들고 싶다면 **Standard Harness**로 시작하세요. 새로운 experience에서 skills, MCP tools, workflows로 만들고 싶다면 **GitHub Copilot harness**로 시작하세요.
</div>

두 경로 모두 같은 채용 시나리오를 사용하므로, 한 경로를 완료하면 다른 경로도 더 쉽게 따라갈 수 있습니다. 두 경로를 모두 완료할 필요는 없습니다.
