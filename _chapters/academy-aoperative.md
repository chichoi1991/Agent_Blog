**Operative**는 Agent Academy의 중급 코스입니다. Recruit 코스에서 Copilot Studio의 기본기를 익혔다면, Operative 코스에서는 실제 업무 시나리오 하나를 처음부터 끝까지 완성합니다 — 바로 Microsoft Dataverse 기반의 **채용 자동화 시스템(Hiring Agent)** 을 구축하는 것입니다.

기초 인프라 배포부터 시작해, 지침(instruction) 작성, 멀티 에이전트 오케스트레이션, 자동 트리거, 모델 선택, AI 안전·콘텐츠 검열, 멀티모달 프롬프트, Dataverse 그라운딩, 문서 생성, MCP 서버 연동, 사용자 피드백 수집까지 — 총 11개의 실습 미션과 1개의 수료 미션으로 구성됩니다.
